# Maths 4GT — Révision géométrie analytique

Application web de révision (cercle, parabole, droites, vecteurs).
100% statique, fonctionne hors-ligne. Aucune installation.

## Mettre en ligne gratuitement
- **Netlify Drop** : glisser ce dossier sur https://app.netlify.com/drop
- ou **GitHub Pages** : pousser ce dossier dans un dépôt, activer Pages.

Tout est en local dans `lib/` (MathJax, GSAP, police Inter).
